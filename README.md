# Код Энергии — лендинг курса

Отдельное Next.js-приложение (не связано с трекером марафона в `1-2-MVP/product-mvp`, кроме того что
переиспользует ту же учётку Supabase и ЮKassa). Задача: маркетинговая страница + приём оплаты по 3 тарифам, без
входа по коду — доступ к самому курсу выдаётся вручную в GetCourse после оплаты.

## Локальный запуск

```bash
npm install
cp .env.example .env.local   # и заполнить реальными значениями
npm run dev
```

Без заполненного `.env.local` страница всё равно открывается и выглядит нормально — кнопки «Оплатить» покажут
«оплата пока не подключена» вместо ошибки, а счётчик мест на тарифе «Персональный» просто не покажется.

## Supabase setup

Переиспользует **тот же проект** Supabase, что уже настроен для марафона (`1-2-MVP/product-mvp`) — учётные данные
можно скопировать оттуда. Нужна всего одна новая таблица — она одновременно и список того, кого добавить в
GetCourse вручную, и источник данных для счётчика мест на тарифе «Персональный»:

```sql
create table public.course_orders (
  id uuid primary key default gen_random_uuid(),
  tier text not null check (tier in ('start', 'support', 'personal')),
  amount_rub numeric not null,
  payment_id text not null unique,
  email text,
  status text not null default 'succeeded',
  created_at timestamptz not null default now()
);

alter table public.course_orders enable row level security;
-- Deliberately no policies: only the service-role key (used by the payment webhook) can
-- read or write this table, same trust pattern as the marathon's tracker_paid table.
```

## YooKassa

Тот же магазин (Shop ID / Secret key), что и у марафона — можно скопировать значения оттуда.

В личном кабинете ЮKassa → **Настройки → Уведомления** добавить адрес вебхука (когда домен будет подключён):

```
https://energy-code.ru/api/payment/webhook
```

и включить как минимум событие `payment.succeeded`.

## Уведомление о новой оплате

При успешной оплате на `NOTIFY_EMAIL` уходит письмо через Resend (тот же аккаунт, что и для напоминания о старте
марафона) с тарифом, суммой и почтой покупателя — по нему вручную добавляете человека в GetCourse.

## Известные незакрытые вопросы (см. память проекта)

- Аккаунт GetCourse ещё не создан — не проверено, встраивается ли трекер энергии внутрь платформы или живёт
  отдельной ссылкой.
- Рассрочка через ЮKassa для тарифов «С сопровождением» и «Персональный» — не настроена, условия не изучены.
- Домен `energy-code.ru` — не куплен и не подключён.
- Точное время суток дедлайна скидки (сейчас — `2026-09-18T23:59:59+03:00`, конец дня по Москве, значение по
  умолчанию, не подтверждено отдельно) — при необходимости поменять в `src/lib/pricing.ts`.
- Оферта в `/oferta` переиспользует реальные реквизиты из оферты марафона, но текст условий (особенно про
  отсутствие возврата) стоит показать юристу или хотя бы перечитать самой перед реальным запуском — это не
  юридическая консультация, а черновик по образцу уже существующего документа.
